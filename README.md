## 🧠 Descripción del proyecto

**cv-prompt-generator** es una herramienta web que genera automáticamente un **prompt formateado** para adaptar mi **currículum vitae (CV)** a una **oferta laboral específica**.

La aplicación toma una oferta de trabajo como entrada y, utilizando una plantilla de CV en español o inglés, crea un texto listo para usar con herramientas de inteligencia artificial como **ChatGPT**, **Gemini** o **Claude**, facilitando la personalización de tu CV para cada puesto.

---

## 🚀 Características principales

- 🌐 **Soporte bilingüe (ES / EN)**: cambia el contenido de mi CV fácilmente entre español e inglés.
- 🧾 **Generación automática de texto**: crea un prompt completo combinando la oferta laboral y mi CV base.
- 📋 **Copiado rápido**: copia el texto generado con un solo clic.
- 💡 **Formato profesional**: mantiene un estilo limpio y coherente para resultados óptimos al adaptar el CV.

---

## 🛠️ Tecnologías utilizadas

- **HTML5**, **CSS3**, **JavaScript**
- Diseño responsive y minimalista
- Enfoque centrado en la experiencia del usuario (UX)
